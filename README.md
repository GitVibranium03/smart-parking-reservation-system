# Smart Parking Reservation System

A web-based parking reservation and vehicle ticket booking system that allows users to check parking slot availability, reserve a parking space, and generate a digital parking ticket.

## 🚗 Project Overview

The Smart Parking Reservation System is designed to simplify the process of finding and reserving parking spaces.

The system allows users to:

- Register an account
- Login to the system
- Enter vehicle details
- Select an available parking slot
- Choose booking date and time
- Validate booking information
- Confirm a parking reservation
- Generate a digital parking ticket
- Print the parking ticket

## ✨ Current Features

- User registration interface
- User login interface
- Vehicle details form
- Parking slot selection
- Available and occupied parking slot display
- Vehicle number validation
- Booking date validation
- Entry and exit time validation
- Parking slot selection validation
- Booking confirmation
- Digital parking ticket
- Print ticket functionality
